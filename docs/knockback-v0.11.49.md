# v0.11.49 肉怪与角色击退调整

按用户要求取消肉怪击退，再将角色已有的击退距离增加一倍。普通模式执行本次平衡调整；测试模式保留原距离、敌人和奖励。只有两个生产文件改动，不新增怪物、技能击退或强制反击。

## 肉怪

`src/enemies/behaviors/MeatBehavior.js` 将链刀命中的 `knockbackDistance` 从36改为0；`src/systems/CombatSystem.js` 移除 `meatKnife` 对角色主动位移的来源许可，旧的正距离载荷也不能推走角色。

链刀仍沿真实飞行段命中第一个存活目标，造成肉怪攻击×2伤害后收回；回收不重复伤害、离手期间不近战、原前后摇和冷却不变。对狼命中仍走真实伤害，但不再产生链刀的额外滑动距离；狼自身既有的短受击停顿保留。死亡、暂停、回收和清场规则不改。

## 角色击退

Combat先保留原抗击退倍率、整数取整、最小距离及旧Boss基准上限，再仅在 `runMode === 'normal'` 时将最终距离×2，之后仍限制在世界边界内。不是翻倍武器输入参数，避免抗性取整或旧上限抵消倍率；同一命中只应用一次。

以短剑原输入72为例，无遮挡时：

| 目标 | 原最终距离 | 普通模式新距离 | 测试模式 |
| --- | ---: | ---: | ---: |
| 战士等普通怪 | 72px | 144px | 72px |
| 肉怪（原0.6抗性） | 43px | 86px | 43px |
| 精英（原0.35抗性） | 25px | 50px | 25px |
| 改版Boss的普通/恢复阶段（原0.8抗性） | 58px | 116px | 58px（直接生成同一目录条目时） |
| 旧Boss基准上限 | 10px | 20px | 10px |

测试模式实际Boss出场仍使用旧Boss，不接入普通模式改版Boss。贴世界边缘时实际位移会被截短；视口外的敌人仍按原进入/回收规则行动，不新增传送或绕后。

普攻及已有击退的重击、动能释放共用Combat路径；例如其技能原输入56/52在普通怪上的最终距离分别为112/104，测试模式仍56/52。当前运行时御剑术、旋转刃本身已重做且不带击退，技能系统/配置不修改，也不为它们新增击退。

## 明确不变

- 普通怪/精英原440ms时长和24px弧高；改版Boss原150ms（无刺蔷薇140ms）、无抬升。
- 原伤害、攻速、抗击退、击退方向、目标死亡安全、Tween替换/暂停/清理及血条跟随。
- Boss技能阶段免击退、皇者全程免击退、原重力反转控制；技能时钟不因普通受击重置。
- 其他怪物/Boss对角色及召唤物的主动击退，既不删除也不翻倍。
- 出场数量、成长、移动、技能射程、商店和奖励。

距离加长会自然增加压制和重新接近时间。仍不保证Boss普攻固定命中，也不补强制反击。技能开始仍需满足实际存活目标、射程、视口及动作状态；被推到射程或视口外不是修改冷却。

## 验证范围

固定执行 `.github/validation-plan.json` 的25项专项/直接回归、`npm run build`、`node --test scripts/test-pr-validation-scope.mjs` 和 `git diff --check`，CI沿用任务范围选择，不跑全套、浏览器、战士命中率或无关商店流程。

新增 `scripts/validate-01149-knockback-distance.mjs` 覆盖真实敌人生成、普通/测试/未指定模式、普攻调用链、重击与动能真实handler、抗性/取整/上限、边界/方向/时长/弧高、连续击退/清理、致死后不位移，以及真实肉怪飞行→角色/狼伤害但无主动击退。既有肉怪、八精英、六Boss及旧Boss等回归继续执行。

原距离断言按新规则更新。撼山将军、无刺蔷薇、无冕之王压力场景保留650/333/180ms慢/普通/快三档：慢档必须自然命中，普通/快档按加长距离自然压制，所有档在合法场景仍于3000ms开始技能。蔷薇连续两次击退后测试视口随角色移动；无冕压力夹具攻击站位100px，100+116仍在原220px突刺射程内，保留准时启动断言，不扩大实际射程。

版本元数据升至0.11.49；70个旧脚本只机械同步版本断言。人数回归中的旧“不能×2”源文本断言改为真实普通/测试位移对照，其余数量/速度等有效检查保留。
