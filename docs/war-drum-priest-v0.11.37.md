# v0.11.37 战鼓祭司

仅普通模式新增后排精英，沿用现有移动、目标选择和左侧离屏回收规则。

- 有效 Lv1：生命68、攻击3、近身自卫间隔2600ms、移动360、站位范围480。
- 每级按基础生命+8%、攻击+3%线性成长，无攻速成长；不是叠乘旧全局难度系数。
- 进入可行动范围后首轮等待3500ms；有范围内普通怪时蓄力600ms，再鼓舞当前520范围内、已进入画面的存活普通怪。
- 鼓舞使普通攻击速度+20%，间隔为原间隔÷1.2，持续3000ms；收招400ms后再冷却6000ms。
- 不治疗，不增加攻击力/移速，不加快技能冷却、飞行、蓄力或收招，不重置已安排的下一次攻击。
- 医师的治疗仍按未鼓舞间隔计算；仅近身自卫受攻速影响，近战后转回治疗也不能提早回血。无鼓舞时原行为保持不变。
- 同一怪被多个祭司鼓舞不叠加；每个来源独立持续，最后来源移除才恢复原始间隔。
- 蓄力、收招不夹普攻；无友军时只在86范围内近身自卫。施法失败不消耗完整冷却。
- 击退、冻结或重力翻转打断祭司并移除其鼓舞；死亡、离屏回收和场景清理也撤回其来源，绝不残留永久攻速。
- 不影响精英、Boss或后续特殊召唤物；角色原攻击、击退和战士自身基础参数不改。
- 每名祭司复用一个 Graphics 展示手鼓、举槌蓄力和友军上方金色小箭头；无事件、Tween或定时器。

## 出场与收益

普通模式第9、12、15、18组中原本就有精英的位置轮换为祭司，首次第9组第3波。其他原有精英位置仍由盾卫/神射手承担；祭司排在普通前排之后。
每波总数、普通怪数量、精英数量、每只15金币及整组击杀收入保持不变。生成间隔参数不改，但前后排顺序变化会改变个别怪的出场时刻。
不增加精英频率，不改Boss前怪潮、三波流程、奖励、商店经济或测试模式原阵容。

## 检查与手机验收

构建、祭司专项、受影响普通攻击/行为管理器/精英轮换与三波流程回归及版本一致性。按项目Skill不跑浏览器或整套回归，也不复测已暂停的战士命中手感。

手机普通模式到第9组第3波：看祭司举槌后附近普通怪出现短暂金色箭头；打断或击杀祭司后消失。反馈这段压力是否明显过高。实际美术和手感仍待用户验证，不宣称整局平衡完成。
