# v0.11.38 狂战士

普通模式新增近战精英：双斧、高攻、较快接近，蓄力三连斩，每一斩重新选目标和判定130范围，不击退；打空不追踪，不冲锋，不加入免控/强制反击。

- 有效Lv1：生命104、攻击10、普攻间隔1800ms、移动300、普攻范围110；每级基础生命+6%、攻击+10%、攻速+1%（上限15%），线性成长。
- 可行动后首轮等待3200ms，550ms蓄力，三斩各一次伤害，250ms间隔；卡帧也不在同一帧补齐多斩。
- 每斩伤害等于当前攻击，130范围单目标；第一斩前没有合法目标则取消，不消耗完整冷却。已经出手后的后续斩可打空，也可命中新的合法目标。
- 蓄力/连斩/900ms收招均停止主动移动且不夹普攻；收招后冷却6200ms，下次普攻仍等原普攻间隔。
- 击退、冻结、重力翻转可打断；未出手不消费完整冷却，已出手被打断进入收招。沿用底层目标选择、普通击退画面、离屏右侧回收。
- 一个复用Graphics显示双斧、蓄力举斧和短暂斩线；无额外事件、Tween、定时器。伤害前推进状态，安全处理同步反伤死亡；回收和场景关闭清理特效/时序。

每波总数、普通怪数、精英数及击杀金币保持不变。出场间隔参数不改，前后排顺序变化可能改变个别怪的出场时刻。
测试模式仍旧阵容/行为/数值。不改战士、其他怪物和Boss参数、鼓舞机制、三波奖励流程、商店或经济。
