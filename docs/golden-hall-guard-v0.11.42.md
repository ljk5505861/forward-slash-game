# v0.11.42 黄金殿卫

仅普通模式新增长枪近战精英，首次14-2，之后17-2，替换已有精英位置。站在普通近战前排之后、远程之前；固定怪物数、精英数、金币、波数和出场间隔参数不变，排序可影响个别生成时刻。

- 有效Lv1：生命112、攻击9、间隔2200ms、范围165、速度160；每级基础生命+8%、攻击+11%，线性成长，无攻速/范围成长。首次Lv14生命228、攻击22，重刺35。
- 两次普通刺击、第三次蓄力重刺，替代当次普攻。普通前摇250ms、收招250ms；重刺前摇600ms、伤害×1.6、收招550ms。成功出手后再等待自身攻击间隔，不叠加额外近战或独立技能。
- 出手重新选择目标并检查165范围，无存活合法目标不扣次数和攻击间隔。低帧不在同帧补多次。每次只伤一个角色或召唤物。
- 不击退、不眩晕、不冲锋、不增加控制免疫。普通击退、冻结、重力翻转可打断未出手前摇；已出手保留攻击间隔，离屏回收保留两轻一重的次数。
- 金色主体、简单冠饰与长枪；重刺前摇亮金色，出手时长枪伸出，短暂刺线，无地面残留。复用一个Graphics，无新Tween/计时器/事件，死亡/清场/关场清理。

五个玩法文件用于配置、独立攻击行为、注册、战斗普攻去重、既有精英位置轮换；同步版本、测试及任务计划。

不改战士命中/基础数值、其他怪物/Boss参数、三波流程、商店、奖励、测试模式原阵容。检查只运行构建、专项与10项直接回归，整套和浏览器不运行。

手机验收：普通模式第14组第2波，看长枪范围、两次普通刺击和第三次明显蓄力重刺、重刺后的停顿是否清楚；反馈伤害与节奏即可。视觉与自然战斗平衡仍待用户验收。
