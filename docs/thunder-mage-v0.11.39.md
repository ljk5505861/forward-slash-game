# v0.11.39 雷法师

仅普通模式新增远程精英：雷电弹普攻、固定落点预警落雷；不击退、不眩晕，沿用日常移动、目标选择和离屏回收。

- 有效Lv1：生命62、攻击8、普攻间隔2400ms、范围480、移动360；每级基础生命+6%、攻击+11%、攻速+1%（上限10%），线性成长。
- 雷电弹飞行400ms，固定轨迹、扫掠检测，首个碰撞目标一次结算；不追踪、不瞬间伤害。一个在途弹，不连发补弹。
- 进入可行动范围后首轮等待4000ms；选合法目标当下位置，固定900ms圆圈预警，随后半径70范围内各一次攻击×1.5伤害。
- 预警位置不跟随角色/召唤物。原目标死亡也不改落点，新目标进入圈可受伤，离开圈可避开；落雷打空仍算出手。
- 预警/650ms收招停止主动移动且不夹普攻；收招后冷却6500ms，下次普攻仍等待自身间隔。启动落雷前等待在途弹结束，避免普攻叠伤。
- 无合法目标不启动技能、不扣冷却；击退、冻结或重力翻转打断预警不消费完整技能冷却，同时清除在途弹。死亡、回收或场景结束撤销所有预警/弹/特效。
- 复用一个Graphics绘制法杖、雷电弹、固定预警与短暂落雷；无事件、Tween或定时器。落雷前推进状态，逐个重验目标和施法者，处理反伤同步死亡/场景销毁。

## 出场与边界

只在第10、13、16组第3波已有精英位置轮换，首次10-3；放在普通近战之后。其余波次的盾卫/神射手/祭司/狂战士保留。
总数、普通怪数、精英数和击杀金币不变；间隔参数不改，角色前后排排序变化可能影响个别出场时刻。
不改战士、其他怪物/Boss参数、鼓舞机制、Boss前怪潮、三波成长、奖励、商店经济或测试模式原阵容。

## 验证与手机体验

构建、雷法师专项、直接相关精英行为管理器/轮换、普通配置、三波流程、版本回归。不跑浏览器、整套或战士命中手感。
手机普通模式第10组第3波首次出现：看雷电弹、900ms固定圆圈预警和落雷是否清楚；目标离开圈后雷仍落在原位置，打断法师应取消预警。反馈该段伤害是否过高。
手机视觉与自然战斗手感待用户验证，自动检查不代表整局平衡完成。
