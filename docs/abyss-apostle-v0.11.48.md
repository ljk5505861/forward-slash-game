# v0.11.48 深渊使徒

普通模式 Boss6 接入人形触手武器、双生、狂暴释放、血门、连续触手打击和巨大触手砸地。用户本轮确认双生在50%血触发，最大/当前血量等分，不回血；狂暴触手有落点预警，攻击一次后消失，不是可击杀的小怪；血门暂时格挡部分伤害，并给自身触手攻击附伤。

只改普通模式 Boss6。测试模式保留虚空君王；前五 Boss、普通怪、精英、商店、奖励、18组三波和 Boss 前怪潮不调整。

## 双生与结算

存活且已进入战斗画面的使徒，在行为帧检测到剩余血量≤最大血量50%时分裂一次。保留原体，右侧合法位置生成另一体；最大血量与当前剩余血量分别精确平分，允许半点生命，不取整增加总血量。例如首战14852上限、7426剩余，会得到两个7426上限、3713当前的独立个体。已死亡的使徒不复活，直接致死攻击不会生成死后分身；原重力反转控制期间等待行为恢复后检测。

两个个体有独立血条、行为实例和技能时钟，共享一次性分裂/胜利记录。分裂没有额外 Boss 出场事件、金币、神器或计杀收益；受全局人数上限约束，生成失败保留全部原血量与分裂机会。右侧位置受世界边界限制，不新增绕后、传送或强制站位调整。

分裂后原体恢复600ms，分身恢复1700ms；分身的既有各技能/普攻时钟比原体延后1100ms。双方技能开始还保持至少1100ms间隔，但不会推迟各自已到期的独立冷却，双方可继续独立行动。

第一个死亡只移除自己的行为/图形/状态，不发 Boss 通关事件，不清掉另一个。全部死亡才发一次 `BOSS_KILLED` 并进入一次原最终胜利。结算标记在同步死亡回调前提交，死亡事件里的连带击杀、燃烧死亡爆炸、重复死亡调用不重复结算；Stage 也独立拒绝仍有存活使徒的提前胜利。

## 初版数值与技能

以下时序和倍率是可调的本轮初版，不是最终整局平衡。生命基数4700、伤害基数30.4（保留旧 Boss6 的38×0.8），线性每级生命+12%、伤害+4%，攻速不随等级增加。首战 Lv19 生命14852、攻击52、移动308，保留旧 Boss6 的首战生命、攻击及移动。补充普攻范围170，释放后间隔2600ms，不继续旧自动普攻或半血狂暴加速。

| 动作 | 初版时序 | 行为 |
| --- | --- | --- |
| 触手普攻 | 前摇180ms、收招280ms | 一个实际存活目标、伤害×1，不主动位移目标 |
| 狂暴释放 | 首次3000ms，前摇500ms，冷却11000ms，持续3000ms，恢复650ms | 每650ms在当前目标位置创建一个固定半径52预警，预警650ms后范围攻击一次、伤害×0.75，随后180ms内消失；无可击杀实体、残留地面或额外召唤收益；长帧不补刷成爆发 |
| 血门 | 首次6000ms，前摇450ms，冷却12500ms，持续3200ms，动作180ms、恢复550ms | 部分格挡40%承伤，触手攻击附加基础攻击×0.3；不改永久攻击/防御/攻速，不叠加、不反射伤害，也不是免伤 |
| 连续触手打击 | 首次9000ms，前摇500ms，冷却7000ms，3次间隔280ms，恢复750ms | 固定前方240、上下90预警区域，每次检查一个最近存活目标；伤害×0.7，目标死亡后可命中仍在区域内的下一实际目标；不转向追踪或加眩晕 |
| 巨大触手砸地 | 首次12000ms，范围420内选落点，前摇950ms，冷却9500ms，动作180ms、恢复1000ms | 固定半径105预警范围，一次砸地伤害×2.1；目标移走不追踪、不补砸，不主动位移目标 |

血门附伤按基础攻击的加法倍率应用：首战普攻52→68，连击每次36→52，狂暴触手39→55，砸地109→125。原防御、护盾、闪避规则沿用；地面攻击沿用不闪避规则。血门在原护甲/减伤后只应用一次部分格挡，包括普通/技能/持续伤害和已结算伤害；到期、死亡、清场立即失效。分裂仅继承当前血门剩余时间，不重开持续窗口。

四个技能时钟独立，最早就绪者优先，一次一个动作；蓄力、连击、持续释放与恢复期间不夹普攻。无目标不启动、不消耗冷却；血门/狂暴释放前摇后无目标、砸地打空、连击整组打空不消耗对应冷却。连击第一次合法命中即提交整组冷却，后续打空不退款；已成功释放的狂暴触手后来落空也不退款。

## 击退、目标与清理

普通/普攻/恢复阶段保留明显击退，沿用改版 Boss 距离倍率0.8、时长150ms；只有技能蓄力、实际动作/持续释放阶段免击退，血门持续增伤/格挡本身不扩展成全程免击退。技能时钟不因普攻击退重置或延后；到期技能可通过 Manager 的受击路径开始蓄力，仍尊重恢复及双生错开间隔，防止连续普攻一直压住技能。不新增旧式强制击退反击。沿用共享寒冷的 Boss 减速/减攻速规则及重力控制，不额外增加免控。

每次释放、命中、冷却及结算状态先提交，再调用同步伤害回调。保存当次真实目标，地面攻击使用目标快照；召唤物死亡/替换不会把同一次攻击转给新对象；反伤造成使徒死亡或对局结束时停止其余范围伤害。狼、鸟、毒王和天书盟友沿用各自真实伤害路径及原受击规则，不改四类 handler。

每个使徒仅复用一个 Graphics，无新事件监听、Tween或定时器。暂停不攻击，时钟/预警/血门按原暂停规则平移一次；既有左侧离屏、右侧重入取消未完成动作和落点，不续血门、不重置冷却、不重新双生。死亡、清场、结束和重开销毁图形、落点、技能标记，独立体不会清掉另一体的行为记录。
