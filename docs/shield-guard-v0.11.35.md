## 范围

- 普通模式内部 `elite` 从精英傀儡替换为盾卫，仍为近战精英、原体型和原出场位置。

- 不调整战士命中、其他怪物/Boss、波数、出场数量/间隔、金币、商店或奖励节点。
- 测试模式保留原精英傀儡及全部原参数，不启用盾卫行为。
- 每波精英带队的频率安排留待后续单独处理，不套用旧四波计划。

## 首版试调

以下是本次试调数值，不代表已经完成整局平衡：

| 属性 | 规则 |
| --- | --- |
| Lv1有效生命 / 攻击 | 150 / 6，不再乘旧全局难度倍率 |
| 每级成长 | 生命增加基础值18%，攻击增加基础值3%，线性、四舍五入 |
| 普攻 | 2000ms，攻击范围96；无额外攻速成长 |
| 移动速度 | 216；举盾期间为受现有减速修正后的45% |
| 首次举盾 | 首次能够行动后3秒；受击退/冻结控制时不能新举盾 |
| 举盾 | 持续1.8秒、减伤50%，期间停止攻击，不是无敌 |
| 再次举盾 | 收盾后5.2秒；收盾后至少350ms才可普攻，原普攻冷却仍有效 |

- Lv1/6/19：生命150/285/636，攻击6/7/9。
- 举盾与已有减伤按乘法合成，收盾、回收、销毁时恢复原减伤。
- 已经举盾后仍能被普通攻击击退；被击退不会刷新举盾时长，期间到期仍会收盾。
- 冻结、重力倒转中断举盾，不授予任何控制免疫。
- 大盾随自身位置绘制；举盾时抬高、放大并使用浅蓝/金色边缘，收盾后恢复。
- 一个可复用图形，使用游戏时间；不新增事件监听、定时器或武器飞行对象。
- 独立行为承担普攻，通用普攻入口跳过盾卫，避免举盾时攻击或重复出手。
