# 怪物改版执行基准（2026-09-20）

设计依据：本轮用户逐个确认的5普通怪、8精英、6Boss。最新代码基线为
v0.11.25 / main 8b5e9a42f03f25c424a183f9d1a172adda6a5b32。
用户已授权设计更新方案并按步骤执行，但不授权自动合并。

## 执行方式与边界

- 一批一个新分支和PR；本批验证、审查完成后由用户手动合并，后续批从最新main开始。
- 平衡改版默认仅普通模式。测试模式保持旧敌人、旧数值与奖励；共用缺陷修复需说明。
- 日常移动、目标选择、站位、左侧离屏后从右侧重新进入的底层规则不重做。
- 未确认的精英（锁链狱卒、炎术士）和Boss（玄甲将军）不加入。
- 保留四波一组、第2波三选一、第4波商店及Boss/职业/遗物/篝火节点。
- 目标波次为普通→精英带队→三选一→普通→精英带队→商店；在第4批接入，不能提前声称已实现。
- 不改商品、价格、刷新、锁定和出售。第4批调整出场数量时同时计算整组基础收入，不能直接把每名新精英设成15金币。
- 战士靠群体自然获得出手机会，不加满10只解锁、挨打计数、强制反击或免疫窗口。
- Boss主要伤害来自技能，普攻为补充。普通状态可明显击退；用击退距离/时长、双方攻速、接近速度和攻击范围实测自然出手机会。
- Boss技能独立计时，普攻击退不延后冷却；蓄力至技能结束免疫击退。皇者全程免疫击退是例外；不擅自扩展成冻结、减速免疫。
- 现有Boss击退反击、狂暴间隔字段等旧逻辑需在Boss批核查；第一批不夹带修改。
- 技能死亡、回收、场景重开均清理计时器/特效/命中记录，防止重复结算和残留伤害。

## 已确认名单与机制（除第1批注明者外均待实现）

### 普通怪

1. 战士：厚血低攻击，近战承伤；10只同时近身时应有人自然出手。成长主生命、微量攻击。
2. 弓箭手：远程主要输出、脆皮；保留现行动轨迹。成长主攻击、微量生命/攻速。
3. 肉怪：大体型、厚血；宽短刀近战；周期性甩出带链短刀，命中伤害和击退后收回，离手期间不近战，回收不重复伤害。
4. 医师：后排周期治疗受伤友军，优先范围内最低生命比例；施法可见，不治疗自己/其他医师，主要成长治疗量。
5. 大师：长细刀近战，高攻、移动与出刀较快；周期性前方刀气，不击退，命中首个目标后消失；成长主攻击。

### 精英

1. 盾卫：大盾近战承伤，周期举盾减伤，举盾期间减速/不攻击。
2. 神射手：远程输出，蓄力三连射，不击退；连射不夹带普攻。
3. 战鼓祭司：后排，周期鼓舞普通怪攻速，不治疗、不叠加、不影响精英/Boss。
4. 狂战士：双斧、高攻、较快；蓄力三连斩，逐次距离判定，不击退，收招停顿。
5. 雷法师：雷电弹普攻、固定落点预警落雷；不击退、不眩晕。
6. 地狱使：召唤头魔，头魔死亡分裂2小魔；小魔不再分裂；每名上限2头魔/4小魔。
   召唤物不产金币、不触发额外金币收益；不全局禁用正常战斗击杀联动。主人死亡后剩余召唤物仍需清理。
7. 赌师：远程丢牌，每第4张为小范围爆炸牌，替代单体结算；不击退、不眩晕、不留地面。
8. 黄金殿卫：长枪近战，范围较长，每第3次蓄力重刺，不击退、不眩晕。

### Boss（顺序固定）

1. 撼山将军：人形、拳头；横扫击退→短停→快速冲锋一次命中→恢复，连招不夹普攻。
2. 无刺蔷薇：红色人形、长细刀；划斩穿过目标造成一次伤害和击退、献花玫瑰爆炸、吸血刺击。
   穿过后不新增转身追击；按底层离屏回收从右侧进入。吸血按实际伤害回血，打空不回。
3. 无冕之王：皇冠黑甲长枪；连续突刺、力劈华山、枪雨、遁入阴影。
   阴影期间免伤/免击退但可攻击，建议只普攻、不叠其他大招；短持续长冷却。
4. 预事者：远程人形、肉球光束；捆绑限制移动不封普攻/技能、分裂两小肉球、瞬移至右侧合法位置。
5. 皇者：大剑；蓄力下突高穿刺伤害、踢腿击退、附魔火剑；全程免疫击退，靠前后摇留空档。
6. 深渊使徒：人形触手；双生、狂暴释放持续召触手、血门格挡加附伤、连续触手打击、巨大触手砸地。
   双生仅一次，各有独立血条，必须全部击败，统一结算一次。分裂不回满；生命分配/触发时机待第6批定值。
