# v0.11.40 地狱使

只在普通模式第12、15、18组第2波替换已有后排精英，首次12-2。保留原计划怪物数量、精英数、出场间隔参数和击杀金币；召唤增加临时在场敌人。

- 地狱使有效Lv1：生命76、攻击3、间隔2600ms、范围420、速度300；每级基础生命+8%、攻击+3%，线性成长，不成长攻速。日常后排移动，近身86内可低伤近战。
- 首次可行动后3200ms启动召唤，650ms举杖预警后召1只头魔；收招400ms，成功召唤后等待5500ms。施法/收招不夹普攻；击退、冻结、重力翻转可打断未完成召唤，不消耗完整技能冷却。
- 每名地狱使最多2只头魔、4只小魔；每只活头魔预留2个分裂名额，满额暂停召唤，清掉小魔后才能补充。不同地狱使各自计数。
- 头魔有效Lv1：生命38、攻击4、间隔2300ms、范围86、速度216；每级基础生命+8%、攻击+5%。小魔：生命16、攻击2、间隔2000ms、范围72、速度250；每级基础生命+6%、攻击+5%。均不成长攻速，沿用近战、击退和离屏回收。
- 头魔战斗死亡原地分裂2只小魔，小魔不再分裂；出生先等待自身攻击间隔，不即时伤害。全局28名在场上限优先，满员边缘分裂可能少于2只。
- 主人死亡只停止继续召唤，不移除已有头魔/小魔；剩余头魔仍可分裂，必须清完才能结算该波。回收主人不重置其召唤名额。
- 召唤物金币为0，击杀事件明确携带 `canGrantGold:false`；当前无额外击杀金币机制。保留击杀计数、血玉等正常战斗击杀联动，不全局屏蔽遗物/技能效果。地狱使本人仍奖励15金币。
- 召唤物为独立 `summon` 类型，不接受只面向普通怪的战鼓鼓舞。清场、关场、结束/重启只清对象与图形，不触发分裂；不注册额外事件、计时器或Tween。

不改战士、其他怪物/Boss数值、角色攻击/击退、三波流程、奖励、商店经济及测试模式阵容。

验证：构建、地狱使实际生成/死亡/分裂/金币/血玉联动/波次阻塞/数量上限/控制/清理专项，以及直接受影响的精英轮换、普通配置、三波流程和版本回归；不跑整套或浏览器。

手机验收：普通模式第12组第2波观察地狱使举杖召头魔；头魔死后应出现2只小魔，小魔不再分裂；先杀主人后仍要清剩余召唤物。看该波是否拖太久、图形是否能分清，反馈现象或短录屏。
