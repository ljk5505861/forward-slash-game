# v0.11.44 无刺蔷薇

普通模式第二个 Boss（第6组后）改为无刺蔷薇：红色人形与细长刀，划斩穿过目标后继续向左离屏，献花在固定落点爆炸，独立吸血刺击按实际扣血回血。测试模式继续使用铁甲暴君。

## 参数与行为

- 有效 Lv1 生命960、攻击11；每级生命+12%、攻击+4%，线性增长。首战 Lv7 生命1651、攻击14，与原第二个 Boss 首战一致。
- 移动300，普通刺击范围150、间隔2000ms、前摇100ms、收招220ms。出手重新检查存活目标与距离；失败不消耗间隔。普通攻击为补充，不触发旧半血狂暴普攻。
- 三技能各有独立就绪时钟，首次为出生后3000/6000/9000ms；只在完整进入屏幕、有合法目标时发动，按最早就绪者出手，一次一个动作。技能与恢复期暂停普通攻击；献花等待爆炸期间不再开始另一技能。
- **划斩**：前摇450ms，持续向左移动，基础速度760；经过线段半径70内的角色或召唤物各最多受伤一次，伤害×1.6、向左击退60。穿过后不转身、不按时长停下，越过现有左侧回收线后，从右侧重新走入并恢复700ms。低帧率跨过回收线时先结算最后一段碰撞，再回收。释放后冷却7000ms，回收保留时钟。
- **献花**：前摇300ms，前摇开始就记录目标坐标；飞行200ms、落地预警800ms，再在半径80内爆炸，伤害×1.6，不击退。落点与预警不随目标移动；已释放的花在普通击退或离屏回收后继续按原位置和时钟爆炸。投出后冷却8500ms，爆炸后恢复550ms。
- **吸血**：前摇550ms，范围165，伤害×1.3；出手重新选取合法目标，空刺不消耗7800ms冷却。命中后按防御、护盾、抵挡、闪避和剩余生命结算后的实际生命扣除恢复等量生命，最多回到自身生命上限。刺击显示180ms，随后恢复600ms；反伤死亡或对局结束后不回血。普通刺击、划斩和献花不回血。
- 普通状态按原 Boss 0.8 倍率产生可见击退，无旧10px距离上限，持续140ms；没有累计击退限制、受击次数反击或额外免控窗口。各技能就绪时可结束普通击退开始前摇，普通击退不重置技能时钟。从前摇至划斩/投花/吸血动作结束免击退；落地等待与恢复期可击退，受击不延长恢复，技能期间仍可受伤。
- 沿用既有寒冷、重力和底层移动/回收规则，不新增减速免疫或绕后。角色与召唤物只有实际受击才位移；毒王若在伤害回调中被替换，新运行时不会继承旧目标的击退。
- 复用一个 Graphics 展示细长刀、划斩尾迹、玫瑰和固定圆形预警，不新增事件、Tween或计时器。死亡立即清理花与图形，避免 Boss 奖励弹窗暂停后残留。回调导致施法者死亡或对局结束时，后续伤害、击退、回血和回收立即停止；毒王转移后不继续施加旧目标的击退。

## 手机验收

普通模式通过第6组、商店和 Boss 前怪潮后进入无刺蔷薇战：观察红色主体与长细刀是否清楚；划斩应穿过后离开左边，再从右侧入场。看到玫瑰预警后离开圆圈，爆炸应留在原落点。观察吸血刺击的扣血和回血提示，以及技能结束后可再次击退。伤害、预警可读性和整体节奏仍需手机体验，反馈现象或短录屏即可。
