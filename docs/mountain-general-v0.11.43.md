# v0.11.43 撼山将军

普通模式的首个 Boss（第3组之后）改为撼山将军：重拳为补充伤害，招牌技能为蓄力横扫、击退、短暂停顿、固定方向快速冲锋。测试模式的狂暴巨兽及其余五个 Boss 保持原实现。

## 参数与行为

- 有效 Lv1 生命640、攻击8；每级生命+12%、攻击+4%，线性增长，不叠加旧全局难度系数。首战 Lv4 生命870、攻击9，与原首个 Boss 相同。
- 普攻间隔2200ms、范围155、移动272；重拳前摇110ms、收招250ms，出手重新检查存活目标和距离。失败出手不消耗间隔。
- 首次技能在出生后3200ms准备就绪，只有完整进入屏幕且有合法目标才发动。横扫前摇650ms，前方水平范围180、纵向半宽90，伤害×1.6，击退72。
- 横扫后停顿240ms，再冲锋480ms；基础速度720，方向在冲锋启动时锁定，后续目标移动不能改变方向。按经过的线段检测半径76内的实际目标，每个角色或召唤物最多命中一次，冲锋伤害×2。横扫命中不保证冲锋命中。
- 横扫释放后开始6000ms的独立技能冷却，沿用既有攻击减速对计时的影响；普通击退不能重置或推迟该时钟。无合法初始目标时不消耗技能冷却；已释放的范围攻击即使落空也进入冷却。
- 连招期间停止普攻，结束后有900ms恢复期；恢复结束才能继续重拳。恢复期可被击退，受击不延长恢复。
- 普通状态按原Boss击退倍率0.8产生可见位移，不应用旧10px距离上限；击退持续150ms。没有累计位移限制、受击次数反击或额外免控窗口。技能到点时结束当前击退，从蓄力至冲锋结束免疫击退，仍可正常受伤。
- 沿用当前寒冷、重力控制与移动/左侧离屏回收规则，不增加减速免疫、转身技能或绕后逻辑。连招离屏回收后进入普通恢复期，冷却保留，不重新获得免费技能。
- 横扫命中角色和存活召唤物后才位移，不添加眩晕；更新召唤物本体、视图和血条。处理毒王只读目标代理及逐帧生成的角色/毒王代理，避免重复命中。
- 赤褐主体、两只拳头，蓄力时抬拳并变亮，横扫短刺线与冲锋尾迹提示。复用一个Graphics，不注册新事件、Tween或计时器；死亡、反伤、结束和销毁均清理图形、状态、速度与目标集合。

## 范围与验证

五个玩法文件为 `src/config/enemies.js`、新建的 `src/enemies/behaviors/MountainGeneralBehavior.js`、`src/enemies/behaviors/EnemyBehaviorManager.js`、`src/systems/CombatSystem.js`、`src/systems/StageSystem.js`。另外同步版本元数据、专项检查、正常模式配置名单和任务验证计划；70个旧检查脚本只进行版本字符串同步。

执行构建、撼山将军专项、旧Boss击退、黄金殿卫及其余已改精英、普通怪配置、三波成长、版本同步，共13项声明验证，并检查验证范围规则与diff。未执行整套回归、浏览器或暂停的战士命中手感验证。

专项走真实spawn、行为管理器和Combat结算，包含角色与真实灵狼/灵鸟运行时、毒王只读代理与天书盟友可用的视图结构、失败/替换目标、固定方向连续碰撞和逐目标去重、控制/暂停/回收/同步死亡及图形清理。普通击退压力的短样本只验证时序：在合法武器距离下，333ms击退节奏仍有普通重拳机会，180ms节奏能压制重拳，两种节奏都不延后技能；不据此宣称自然整局平衡通过。

手机验收：普通模式通过第3组、商店与Boss前怪潮后，观察抬拳蓄力→横扫击退→短暂停顿→冲锋→恢复停顿是否清楚，以及重拳、连招伤害和节奏。技能期间应仍会掉血但不被击退，结束恢复期可被击退。反馈现象或短录屏即可。
