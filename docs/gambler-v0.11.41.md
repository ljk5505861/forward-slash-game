# v0.11.41 赌师

仅普通模式新增远程精英，首次13-2，之后16-2，替换已有后排精英位置。固定怪物数、精英数、金币和出场间隔参数不变，前后排变化可影响个别生成时刻。

- 有效Lv1：生命60、攻击7、间隔2300ms、范围480、速度360；每级基础生命+5%、攻击+11%、攻速+1%（上限15%），线性成长。
- 前三张牌各350ms出手预告，第四张红牌650ms预告。实际丢出才计数、消耗普攻间隔；未出手被控制/目标死亡不扣次数与间隔。打空或出手后被打断仍算已丢出。
- 一张在途牌，450ms固定轨迹，不追踪；连续扫掠选第一个碰撞目标。普通牌只造成一次单体伤害；第4张在碰撞处或射程末端爆炸，半径64、攻击×1.35，替代单体伤害，每个范围内目标一次结算。
- 不击退、不眩晕；爆炸只显示180ms短圈，不留下持续地面。蓄力期间停下，不夹带普攻或近战。通常移动、目标选择、角色击退与离屏回收沿用底层。
- 击退、冻结、重力翻转撤销预告与在途牌；离屏回收清牌但保留已丢出次数。死亡/关场清理图形、牌和落点，逐次伤害前重验施法者、目标和位置，处理同步反伤死亡或结束。
- 一个复用Graphics，无新事件、Tween或计时器。

不改战士、其他怪物/Boss参数、三波成长、商店、奖励、测试模式原阵容。

检查：构建、赌师专项、已有精英管理器/轮换、普通配置、三波流程及版本回归；不跑整套、浏览器或战士命中手感。
