# v0.11.36：精英神射手（普通模式）

基线：main `be9692e0f00ab6b6b357aeeef356a318f3a8f543` / v0.11.35。
按已确认的远程输出、蓄力三连射、不击退设计，单怪更新。

## 接入范围

- 普通模式第8/10/12/14/16/18组，仅原本含精英的波，将该精英槽替换为神射手，排在普通前排之后、其他后排之前。首次出现为第8组第1波。
- 其他已有精英槽仍为盾卫。每波总数量、普通怪种类/数量、精英数量与基础金币总量均不增加。
- 原出场间隔参数不变；后排排序会改变该波个别敌人的出场时刻，这是远程精英站位调整，不是新增敌人。
- 不接入旧四波计划或全面提高精英频率。不修改Boss前怪潮、Boss、战士命中、其他怪物参数、技能/商店奖励位置、经济或测试模式波表。
- 新神射手条目复用archer行为标识以跳过通用近战，仅普通模式指定ID绑定新的独立行为；普通弓箭手保持原行为。
