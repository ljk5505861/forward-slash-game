# v0.11.46 预事者

普通模式第四个 Boss 改为预事者：远程人形，肉球发射类激光；三个独立技能为捆绑、分裂肉球、瞬移。测试模式仍是原深渊吞噬者，Boss5–6和前面三位已改 Boss 不变。

## 初版参数和行为

数值为本轮初版，不是此前已经确认的最终平衡。有效Lv1生命2300、攻击19，生命每级+12%、攻击每级+4%，线性成长、攻速不随等级增加。首战Lv13生命5612、攻击28，保留原Boss4水平；移动286，光束范围520、站位380±原距离缓冲，沿用底层日常接近、左侧离屏及右侧重入规则。

| 动作 | 初版时序 | 行为 |
| --- | --- | --- |
| 肉球光束 | 蓄力350ms、显示180ms、收招280ms，命中释放后间隔2600ms | 蓄力时锁定射线方向，预警线与实际射线一致；16半径判定，沿线最近的一个实际存活目标受伤，不穿透、不追踪、不击退。原目标死亡时可命中该射线上的替代目标；射线落空不消耗攻击时钟，仍显示并收招 |
| 捆绑 | 首次3000ms，前摇500ms，释放后冷却7000ms，动作显示180ms、恢复600ms | 480范围内锁定目标，触须预警，伤害×0.35；实际扣血且原单位仍合法时限制主动移动1800ms，不封攻击、技能或治疗。没有合法目标、原目标死亡或离开范围不消耗冷却；躲闪/完全挡伤不附加束缚 |
| 分裂肉球 | 首次6000ms，前摇650ms，释放后冷却9500ms，显示180ms、恢复650ms | 同时最多两颗，必须有两个本地和全局人口空位才施法；两颗独立生命和光束，可被击毁，存在8500ms后消失。没有目标、满上限或生成失败不消耗冷却，不堆叠额外肉球 |
| 瞬移 | 首次9000ms，前摇400ms，释放后冷却10000ms，显示180ms、恢复650ms | 肉球收缩、移动到当前屏幕右侧60%区域中的另一处合法位置，完全入屏、位于角色前方并保留100间隙，与原位置至少差80。释放时重新核对相机和世界边界；没有合法位置/目标不消耗冷却。只改变位置，不附加免伤，不到左侧或背后 |

小肉球有效Lv1生命54、攻击7，每级生命+6%、攻击+4%，首战Lv13生命93、攻击10；移动180、光束范围460、站位320。生成后至少600ms才开始350ms光束前摇，命中释放后间隔1800ms，没有出生即时伤害。方向预警、单目标射线、收招和落空规则与主肉球一致。

三个技能时钟独立，最早就绪者优先，一次一个动作，不在技能/恢复期夹其他动作。普通光束前摇可被击退打断；技能前摇与释放动作仅免击退、不免伤；恢复期可击退，受击不延长恢复。普通击退用原Boss0.8倍率、可见位移150ms，不采用旧10px上限，不增加累计击退限制、受击次数反击或额外免控窗口；普通击退不改技能时钟，技能就绪可结束当前击退进入前摇。保留寒冷、重力和暂停规则。

## 束缚和生命周期

束缚记录持有真实角色/召唤物引用及到期时间；毒王、灵鸟和天书单位替换后不把效果转给新单位。到期直接按战斗时钟判断，移动入口无需等管理器下一帧才解除。角色只暂停自动移动；狼暂停追击/跟随、仍可在范围内攻击；灵鸟暂停跟随、仍能治疗；毒王暂停位置更新、撕咬/领域继续；天书盟友暂停跟随、攻击继续。不改它们原数值、目标和动作时钟，也不额外免疫伤害/强制击退。

先提交攻击、释放和冷却状态，再调用伤害回调；同步死亡、反伤杀死施法者、目标替换或对局结束后不得追加束缚或伤害。没有新事件、Tween或计时器，图形复用Graphics。暂停不推进施法/伤害；时钟调整按各对象处理一次，不能重复延长肉球寿命；离屏回收取消未释放动作但不重置技能时钟，不续已释放束缚或肉球寿命。束缚到期、目标死亡、Boss死亡、清场或对局结束解除引用和图形。

肉球击毁仍使用正常战斗击杀联动，但不产额外金币；到期及Boss死亡清理不伪造战斗击杀，不额外发奖励。Boss死亡先清理束缚和肉球，再进入原神器奖励；Boss4不增金币，神器和后续篝火仍各结算一次，不等待肉球死亡额外结算。

## 手机验收（待完成）

普通模式通过第12组商店及Boss前怪潮，进入Boss4：

1. 看肉球蓄力线后观察短促光束，方向不追踪移动目标，提示应与命中线一致。
2. 被触须捆绑后应暂时停止主动移动，但普攻/技能继续；召唤物仍可攻击或治疗。结束或Boss死亡后立即恢复移动。
