# v0.11.34 商店移至 Boss 前组奖励

本项按用户确认只调整普通模式奖励节点，不加额外3波，不改金币、价格、怪物或技能数值。

- 每组仍3波。第3、6、9、12、15、18组结束后直接商店，替换该组技能三选一；离店再进入原有后续节点及Boss前怪潮。
- 其余12组结束后只出技能三选一；选择完成直接推进，不再紧接商店。
- 第9组保留商店→进阶职业→篝火→Boss3怪潮；其他Boss奖励、职业、篝火及特殊节点保持原样。不新增独立的重复Boss前商店。
- 普通模式合计54波、12次组技能奖励、6次商店、6个Boss；等级仍每组提升一次，不改敌人等级推进。结算等待保留，拒绝错误或重复关闭回调。
- 测试模式仍4波一组、第2波技能奖励、第4波商店，玩法和价格不变。
- 技能奖励减少与商店间隔拉长属于本次已确认效果；自然游戏中成长强度及金币积压尚未平衡验证，不提前改数值补偿。

## 验证范围

构建、18组节点流程、清波等待、测试模式原流程及商店行为回归。同步更新手动浏览器流程脚本，但本次仅检查语法，不启动浏览器或全量回归。

## 手机验收

1. 普通模式第1、2组结束：只有三选一，选完继续战斗，无商店。
2. 第3组结束：只有商店，无三选一；离店后进入原怪潮和Boss1，不能再弹第二个商店。
3. 后续经过第9组时：商店后仍有进阶职业和篝火。留意技能成长变慢、金币积压的体感，后续再单独校准。
