# v0.11.31 肉怪：普通怪第二批的第一小项

- 仅普通模式将原重甲守卫（内部 ID `armored_guard`）替换为肉怪。原出场位置、数量、间隔和金币不变；最早第2组出现。
- 大体型，持宽短刀；Lv1 生命128、近战伤害3、普攻间隔2400ms。每级线性增加基础生命18%、攻击3%，不增加攻速。
- 首次甩刀等待4500ms，650ms可见蓄力，射程360；出刀550ms、回收350ms，收刀后冷却6500ms。
- 飞行路径命中首个有效目标一次，伤害为当级近战的2倍；命中角色时击退36，世界边界截断。技能阻挡/闪避不击退；回收不伤人。
- 蓄力、出刀、回收期间不叠加近战。冻结、击退或重力翻转打断本次甩刀，死亡/离屏回收/场景销毁清理武器状态。
- 保留移动、选目标和左出右进规则；战士、弓箭手、测试模式以及三波→技能→商店节奏不变。
- v0.11.30 为暂停中的战士 PR 版本，本项使用 v0.11.31，不带入其改动。

## 手机验收

1. 普通模式到第2组：确认大体型“肉怪”、宽短刀和连刀的链条可见。
2. 留一只肉怪存活：观察蓄力甩刀、击退及拉回；回收时不应再次扣血，离手时不应同时近战。
3. 甩刀中击杀肉怪或重开：确认没有残刀、链条和后续伤害。
