# v0.11.45 无冕之王

普通模式第三个 Boss（第9组后的进阶职业雕像、Boss前怪潮之后）改为无冕之王：皇冠、黑甲与长枪，连续突刺、力劈华山、枪雨、遁入阴影四技能。测试模式仍是训练场守卫；第三个 Boss 并非最终 Boss。

## 参数与时序

- 有效 Lv1 生命1408、攻击16；每级生命+12%、攻击+3.5%，线性成长，攻击间隔不随等级加速。首战 Lv10 生命2929、攻击21，与原第三个 Boss 相同。普通刺击范围175、间隔2400ms、前摇110ms、收招250ms；移动272，保留底层接近、左侧离屏与右侧重入，不新增绕后逻辑。
- 四技能时钟独立，首次在出生后3000/6000/9000/12000ms就绪；完整入屏、有合法初始目标时，最早就绪者开始前摇，一次一个动作，恢复期不释放其他技能。没有合法初始目标不消耗冷却。
- **连续突刺**：前摇420ms，三枪间隔220ms，范围220，每枪伤害×0.8，不击退。每枪重新检查存活目标与距离，可换成召唤物；第一枪失败不消耗6500ms技能冷却，之后落空的枪不伤害旧目标。低帧率一次更新最多补一枪，避免数枪同帧爆发。最后刺击显示180ms，之后恢复650ms。
- **力劈华山**：前摇700ms，方向在前摇时锁定，前方水平范围205、纵向半宽95，一次伤害×2.2并击退80。角色和召唤物分别结算，身后或超出范围不受伤；释放后冷却8000ms。动作显示180ms，恢复850ms。
- **枪雨**：前摇500ms，前摇开始记录目标区域；三批、每批三枪，横向偏移-90/0/+90，批次间隔450ms。每枪独立预警600ms、下落220ms，落地半径32内伤害×0.65，不击退。落点固定，不追踪目标或回退到角色；每枪每个实际目标只结算一次，没有持续地面伤害。释放后冷却10000ms；最后一批落地后恢复650ms。已释放的固定预警与下落时钟跨离屏回收保留，死亡立即清理。
- **遁入阴影**：前摇350ms，阴影持续3000ms，主体透明度0.3；期间免伤、免击退，仍可按底层行动接近目标，并仅使用普通刺击，不叠加另外三技能。释放后冷却12500ms，结束恢复600ms。普通攻击、技能、燃烧、毒、反伤以及已结算伤害均走阴影免伤检查；结束时间直接按战斗时钟判断，即使本帧行为管理器尚未更新，也立即恢复可受伤、可击退。离屏重入保留剩余时间，不重新赠送阴影。
- 除阴影外，技能前摇与实际动作只免击退，不免伤；普通状态和恢复期可击退。普通击退按原Boss 0.8倍率产生可见位移，持续150ms，不用旧10px位移上限。没有累计击退限制、受击次数反击或额外免控窗口；普通击退不重置技能时钟，技能就绪可结束当前击退开始前摇。恢复期受击不延长恢复。
- 沿用既有寒冷/重力减速与暂停时钟，不新增减速免疫。暂停不继续伤害或施法，计时调整不会把零值阴影标记误激活。
- 复用一个 Graphics 画皇冠、长枪、重劈、枪雨与阴影提示；皇冠位于盔甲顶部，坐标检查覆盖与燃烧/毒状态行分离，不改共享UI，真机可读性仍待验收。不新增事件、Tween或计时器。先提交动作、命中或落枪状态，再调用伤害回调；目标、施法者或场景在回调中死亡/销毁时停止后续伤害和击退。死亡和对局结束清理预警、图形、阴影时间、透明度、速度和引用，避免奖励弹窗暂停后残留。

## 修改范围和检查

五个玩法文件：`src/config/enemies.js`、新建 `src/enemies/behaviors/UncrownedKingBehavior.js`、`src/enemies/behaviors/EnemyBehaviorManager.js`、`src/systems/CombatSystem.js`、`src/systems/StageSystem.js`。另同步版本元数据、专项检查、配置名单、验证计划和本文档。69个旧脚本仅机械同步版本；旧Boss击退检查另适配免击退函数新增的当前时间参数，仍保留判断早于位移/Tween创建、免击退返回false等全部16条断言。撼山将军专项的 Boss3 旧模式边界由本专项真实 spawn 检查替代，Boss4–6原断言保留。

检查清单为 `npm run build`、`.github/validation-plan.json` 声明的16项专项/直接回归、`node --test scripts/test-pr-validation-scope.mjs`、`git diff --check`。包括无冕之王、无刺蔷薇、撼山将军、旧Boss击退、八种已改精英、普通配置、三波流程、Boss奖励与版本；不跑整套回归、浏览器或战士命中手感测试。

无冕之王专项走实际 spawn、行为管理器、TargetingSystem、Combat 和燃烧/毒状态系统，覆盖技能独立就绪、逐枪空刺/替换目标/低帧率、重劈玩家和召唤物位移、固定预警的分批逐枪结算、阴影移动与普通刺击/全伤害路径/精确到期、暂停/回收/计时/减速/同步死亡/对局结束清理、第三Boss神器与篝火只结算一次。

普通受击短样本仅验证 Boss 时序：333ms节奏仍有普通刺击机会，180ms节奏可压制普通刺击，两者不推迟已就绪技能；不据此宣称整场平衡已完成。首战生命和攻击保持原水平，但新技能伤害和免伤占比仍需要手机体验。

无刺蔷薇、撼山将军、其他已实现怪物的参数、三波循环、商店/技能池、剩余 Boss 出场及测试模式奖励不变。第三Boss不新增金币奖励，神器后仍进入原篝火节点。
