# v0.11.47 皇者

普通模式 Boss5 改为皇者：大剑；蓄力下突高穿刺伤害、踢腿伤害和击退、限时火剑附魔；全程免疫击退，靠前后摇留空档。不加入火地、爆炸、灼烧伤害或其他技能。测试模式仍是原雷霆战争机，前四 Boss 及 Boss6 不变。

## 初版数值与时序

时序与倍率为本轮初版，不是此前确认的最终平衡。有效 Lv1 生命3300、基础攻击24，生命每级+12%、攻击每级+4%，线性成长，攻速不随等级增加。首战 Lv16 生命9240、攻击38，保留原 Boss5 水平；移动296，日常接近/目标选择及左侧离屏、右侧重入规则保留。

| 动作 | 初版时序 | 实际行为 |
| --- | --- | --- |
| 大剑普攻 | 前摇220ms、收招320ms，释放后间隔2400ms | 补充伤害，范围165，一个实际存活目标，一次结算，不击退；关闭普通模式皇者的旧自动普攻/半血狂暴 |
| 蓄力下突 | 首次3000ms，前摇900ms，释放后冷却7000ms、动作180ms、拔剑恢复1400ms | 固定前方200、上下90预警区域，范围内最近的一个实际存活目标，伤害×3；方向不在蓄力后追踪翻转。穿刺是攻击类型，不另加忽略防御/护盾规则；不击退，不多段重复命中 |
| 踢腿 | 首次6000ms，前摇350ms，释放后冷却6500ms、动作180ms、恢复650ms | 前方125、上下70内一个实际目标，伤害×1.1、位移96；不吃火剑增伤，不额外增加眩晕/定身 |
| 附魔·火剑 | 首次9000ms，前摇650ms，释放后冷却14000ms、动作180ms、恢复550ms | 4500ms内大剑普攻和下突伤害×1.5，仅剑击增伤，不改基础攻击/攻速；到期立刻停止增伤，并留700ms结束停顿 |

首战基础普攻38、下突114、踢腿42，火剑普攻57、火剑下突171；伤害仍走原防御、护盾和闪避结算。每个技能有独立绝对时钟，最早就绪者优先，一次一个动作，技能/恢复期间不夹普攻或其他大招。无目标不启动；下突/踢腿前摇后打空不消耗对应冷却，仍保留收招；附魔释放时无目标不消耗冷却、不附魔。

火剑结束不取消正在进行的下突/踢腿；到期后的剑击按基础伤害，当前技能收招结束后追加一次结束停顿。已经结束的火剑不继续增加伤害，不续新的火剑窗口。

## 免击退、目标身份及生命周期

皇者在普攻、技能、恢复和火剑结束停顿期间都免击退，但任何阶段仍可受伤；不增加免伤、反击次数、累计受击解锁或新免控窗口。共享寒冷系统现有 Boss 规则是减速/减攻速而非直接冻结，本轮不改全局冻结门槛，也不因免击退额外免疫寒冷减速或既有重力控制。

踢腿复用 Combat 的真实玩家/召唤物伤害及位移路径：玩家躲闪不位移；其余防御/护盾规则不改。狼使用原受击队列滑退，距离只累计一次96，不再额外叠一份即时位移；保留原受击短停。鸟、毒王和天书盟友走共享位移，并同步自身/血条/领域/盟友图形。保存伤害前的真实单位引用，伤害回调造成死亡、移除、替换、施法者死亡或对局结束时不把位移转给旧/新单位。旧蔷薇/无冕之王的路径不重构。

先提交释放/冷却/命中状态，再调用伤害回调；每次下突/踢腿/剑击只结算一次。暂停不施加伤害，计时调整只处理一次。离屏回收取消未释放动作并收招，不重置独立时钟、不续已释放火剑。死亡、清场、对局结束删除图形和火剑引用，不产生残留伤害或标记。本轮只使用一个复用 Graphics，没有新增事件监听、Tween或定时器。

Boss5 不增加金币，仍领取一次原神器奖励后进入原篝火，不变为中段 Boss 或最终 Boss。

另同步版本元数据、70个旧脚本的纯版本断言，配置名单新增皇者；撼山将军专项中的旧 Boss5 未迁移断言由本轮真实正常/测试 spawn、首战属性、事件和奖励专项替代，Boss6 原断言保留。不放宽有效断言，不因失败缩减检查。

## 手机验收（待完成）

普通模式通过第15组商店及 Boss 前怪潮进入 Boss5：

1. 观察大剑高举蓄力与下突预警，下突只命中一次；拔剑恢复期间不夹攻击。踢腿应造成伤害和一次击退，狼不应出现双倍滑退。
2. 观察火剑剑刃特效及限时增伤，踢腿不变强；火剑结束有停顿，无持续火地/爆炸/灼烧残留。全阶段击退皇者都不位移，但攻击仍能扣血。
3. 击败后只出现一次原神器奖励、进入原篝火；暂停/继续或离屏重入不能刷新火剑持续时间、产生残留下突或重复奖励。

预警可读性、免击退时的压迫感、技能伤害和恢复空档仍待用户真机体验，未宣称通过。
